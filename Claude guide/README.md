# Claude guide

Support files for Mike Lucki's "Claude for Teachers" Google Doc, a starter guide and log for colleagues.

Start a new Cowork task with: *"Read Claude guide/CLAUDE.md and timeline.md in my projects folder, then help me with the next part of my Claude guide."*

- `CLAUDE.md`: instructions for Claude (doc links and tabs, voice, rules, how screenshots get into the doc)
- `timeline.md`: what's been built and when
- `ideas.md`: ideas for future, smaller parts
- `prompts.md`: copy-ready prompts for colleagues
- `screenshots/`: images used in the November update
